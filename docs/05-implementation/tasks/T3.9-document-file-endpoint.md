## Mục tiêu

`GET /api/v1/documents/{id}/file` trả PDF với kiểm tra quyền và hỗ trợ tải theo khoảng (Range) để trình xem mở trang nhanh.

## Bối cảnh

- Tệp chỉ phục vụ qua ứng dụng, không có URL công khai (SAD §2.3).

## Phạm vi

**Trong phạm vi**

- Endpoint truyền tệp
- Hỗ trợ `Range`
- Header an toàn

## Các bước thực hiện

1. Kiểm tra quyền (cùng quy tắc với danh sách tài liệu).
2. Không tồn tại hoặc đã xóa → 410 `DOCUMENT_GONE`.
3. Truyền tệp qua `FileStorePort.open`, hỗ trợ `Range`; `Content-Type: application/pdf`, `Content-Disposition: inline`, `X-Content-Type-Options: nosniff`, không cache công khai.
4. Không log nội dung; ghi metric số lần mở.

## Tiêu chí chấp nhận

- [ ] Given tài liệu READY, When GET, Then 200 với PDF đúng.
- [ ] Given header `Range`, When GET, Then 206 đúng khoảng.
- [ ] Given tài liệu đã xóa, When GET, Then 410.
- [ ] Given chưa đăng nhập (sau T4.1), When GET, Then 401.
