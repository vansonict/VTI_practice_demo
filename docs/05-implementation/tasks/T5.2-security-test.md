## Mục tiêu

Không còn lỗ hổng mức High/Critical: lỗi web thường gặp, upload độc hại, kiểm soát truy cập, rò rỉ dữ liệu, prompt injection qua câu hỏi và qua nội dung PDF.

## Bối cảnh

- Mô hình đe dọa ở SAD §4.1.

## Phạm vi

**Trong phạm vi**

- Kiểm thử ứng dụng web (XSS khi hiển thị câu trả lời, CSRF, injection)
- Upload: file giả PDF, file lớn, file độc hại
- Kiểm soát truy cập (bảng quyền)
- Rò rỉ: log, analytics, header, thông báo lỗi
- Bộ prompt injection mở rộng (≥ 30 ca)

## Các bước thực hiện

1. Chạy công cụ quét tự động cho ứng dụng web trên môi trường test.
2. Thử XSS: câu trả lời chứa HTML/script (từ nội dung PDF) phải hiển thị như văn bản.
3. Thử upload: đổi đuôi, PDF chứa script, file vượt giới hạn, nhiều file song song.
4. Chạy lại test bảng quyền (T4.2) và test chuỗi đánh dấu (T4.3).
5. Mở rộng bộ đối kháng (T3.3) lên ≥ 30 ca; chạy và chấm.
6. Ghi lỗ hổng theo mức độ; sửa High/Critical; kiểm lại.

## Tiêu chí chấp nhận

- [ ] 0 lỗ hổng High/Critical còn mở (G-11).
- [ ] Bộ prompt injection: 0 ca vượt quy tắc grounded.
- [ ] Test bảng quyền 100% đạt (G-09); test chuỗi đánh dấu 0 xuất hiện (G-10).
- [ ] IT/Bảo mật ký báo cáo.
