## Mục tiêu

Mỗi file trong một lần upload có kết quả riêng; phát hiện file trùng nội dung và xử lý theo quyết định PQ-03.

## Bối cảnh

- Đề xuất trong PRD: cảnh báo và cho chọn *Thay thế* hoặc *Giữ cả hai*.

## Phạm vi

**Trong phạm vi**

- Tính `content_hash` khi nhận file
- Phản hồi trùng theo PQ-03

## Các bước thực hiện

1. Tính hash nội dung khi nhận file (trước khi lưu tệp).
2. Nếu trùng tài liệu chưa xóa: trả kết quả file đó với `duplicateOf: documentId` và không tạo bản ghi mới, trừ khi request có tham số `onDuplicate=keep_both|replace` (theo PQ-03).
3. `replace`: xóa tài liệu cũ (dùng logic T2.4) rồi tạo mới; `keep_both`: tạo mới bình thường.
4. Cập nhật OpenAPI cho tham số và trường `duplicateOf`.

## Tiêu chí chấp nhận

- [ ] Given upload lại đúng một file đã có, When không có `onDuplicate`, Then kết quả file đó có `duplicateOf` và không có bản ghi mới.
- [ ] Given `onDuplicate=replace`, When upload, Then tài liệu cũ bị xóa, tài liệu mới `PROCESSING`.
- [ ] Given 3 file trong đó 1 trùng, When upload, Then 2 file được nhận bình thường.
