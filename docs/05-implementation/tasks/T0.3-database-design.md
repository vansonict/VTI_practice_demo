## Mục tiêu

Chuyển mô hình dữ liệu logic (SDD §3.5) thành schema vật lý PostgreSQL + vector với ràng buộc, chỉ mục và migration chạy được.

## Bối cảnh

- Một CSDL duy nhất chứa dữ liệu nghiệp vụ, đoạn văn bản, vector, hàng đợi job, sự kiện (SAD §3.1).
- Xóa tài liệu phải xóa đoạn văn bản trong **cùng một giao dịch** (AC-005).
- Số chiều vector lấy từ ADR embedding (T0.1): **768** theo [ADR-004](../adr/ADR-004-embedding-model.md); đặt trong một hằng số để đổi được.
- Prompt sẵn có: `databaseDesign_SQL_prompt.md`, `databaseDesign_VectorDB_prompt.md`; checklist `Database_Design_Checklist.xlsx`.

## Các bước thực hiện

1. Chạy prompt database design với đầu vào SDD §3.5, SAD §2.3 làm bản nháp.
2. Định nghĩa bảng theo phần Đặc tả: kiểu dữ liệu, NOT NULL, giá trị mặc định, CHECK cho enum.
3. Khóa ngoại: `chunks.document_id` ON DELETE CASCADE; `citations.chunk_id` ON DELETE SET NULL (trích dẫn cũ vẫn giữ tên tài liệu và trang đã sao chép).
4. Chỉ mục: HNSW (cosine) trên `chunks.embedding`; GIN trên `chunks.tsv`; btree `documents(status)`; `processing_jobs(state, locked_until)`; unique `feedback(message_id, user_id)`; `analytics_events(occurred_at)`; `messages(conversation_id, created_at)`.
5. Cột sinh `chunks.tsv` từ `text` với cấu hình ngôn ngữ phân tích theo OQ-007 (tạm `simple` nếu chưa chốt).
6. Viết migration lên/xuống; chạy trên CSDL trống; chạy lại không lỗi.
7. Viết seed dev; không có dữ liệu thật.
8. Review theo checklist database; ghi các điểm phụ thuộc OQ-009 (cột `messages.text`, thời gian lưu giữ).

## Đặc tả

| Bảng | Cột chính | Ghi chú |
|---|---|---|
| `users` | id, display_name, role (BD/MANAGER), password_hash?, external_subject?, active, created_at | `password_hash` chỉ dùng khi đăng nhập local |
| `documents` | id, name, size_bytes, page_count?, status (PROCESSING/READY/UNUSABLE), unusable_reason?, retryable, content_hash, file_ref, uploaded_by, uploaded_at | index status; `content_hash` cho PQ-03 |
| `chunks` | id, document_id, page, ordinal, text, embedding vector(N), tsv | Đoạn **không vượt ranh giới trang** |
| `processing_jobs` | id, document_id, state (QUEUED/RUNNING/DONE/FAILED), attempts, locked_until?, last_error?, created_at, updated_at | Hàng đợi (SDD D-05) |
| `conversations` | id, user_id, started_at | |
| `messages` | id, conversation_id, role (USER/ASSISTANT), kind? (ANSWER/NOT_FOUND/ERROR), text?, error_type?, latency_ms?, created_at | `text` có thể null nếu OQ-009 không cho lưu |
| `citations` | id, message_id, chunk_id?, document_id, document_name, page, position | Sao chép tên + trang tại thời điểm trả lời |
| `feedback` | id, message_id, user_id, rating (HELPFUL/NOT_HELPFUL), comment?, updated_at | unique(message_id, user_id) |
| `analytics_events` | id, name, user_ref, session_id, properties jsonb, occurred_at | Không chứa nội dung |
| `audit_log` | id, actor_id?, action, target?, occurred_at, ip? | |

## Tiêu chí chấp nhận
