## Mục tiêu

Viết đặc tả OpenAPI 3 đầy đủ cho mọi endpoint trong SDD §3.6, gồm schema request/response, mã lỗi và quyền, để frontend và backend làm song song.

## Bối cảnh

- SDD §3.6 mới có hợp đồng mức thiết kế (14 endpoint, mô hình lỗi). SAD §2.4 chốt tiền tố `/api/v1`.
- Prompt sẵn có: `References/design/apiDesign_prompt.md`; checklist: `References/design/API_Design_IEEE-1016-2009Checklist.xlsx`.
- `NOT_FOUND` (không có thông tin trong kho) là **kết quả hợp lệ** HTTP 200 `kind=NOT_FOUND`, không phải lỗi.

## Các bước thực hiện

1. Chạy prompt `apiDesign_prompt.md` với đầu vào SDD §3.6, SAD §2.4–2.5, UseCase_Specification làm bản nháp.
2. Định nghĩa schema chung: `Error`, `Document`, `DocumentStatus`, `UnusableReason`, `UploadResult`, `Conversation`, `Message`, `MessageKind`, `Citation`, `Feedback`, `WeeklyStats`, `AnalyticsEvent`, `Me`.
3. Định nghĩa 14 endpoint theo bảng ở phần Đặc tả, mỗi endpoint có: mô tả, quyền, request, response thành công, các mã lỗi có thể trả.
4. Mô tả xác thực bằng cookie phiên (`securitySchemes` kiểu apiKey trong cookie); ghi chú phương án OIDC nếu OQ-008 chọn IdP.
5. Thêm ví dụ (`examples`) cho 3 loại kết quả hỏi đáp: ANSWER, NOT_FOUND, ERROR.
6. Chạy công cụ lint OpenAPI (chọn ở T0.1) và sửa hết lỗi.
7. Review với frontend, backend, QA; review theo checklist API; lưu kết quả review cạnh file.

## Đặc tả

| Method | Path (`/api/v1` + …) | Quyền | Thành công | Lỗi chính |
|---|---|---|---|---|
| POST | `/auth/login` | Công khai | 204 + cookie | 401 `AUTH_INVALID` |
| POST | `/auth/logout` | Đăng nhập | 204 | 401 |
| GET | `/me` | Đăng nhập | 200 `Me{id, displayName, role}` | 401 |
| POST | `/documents` (multipart, nhiều file) | BD | 202 `UploadResult[]` (mỗi file: `documentId` hoặc `error`) | 401, 403, 413/422 theo từng file |
| GET | `/documents` | BD | 200 `Document[]` | 401, 403 |
| POST | `/documents/{id}/retry` | BD | 202 | 404, 409 (không ở trạng thái lỗi xử lý) |
| DELETE | `/documents/{id}` | BD | 204 | 404, 403 (phạm vi theo OQ-010) |
| GET | `/documents/{id}/file` | BD | 200 `application/pdf`, hỗ trợ `Range` | 404, 410 `DOCUMENT_GONE` |
| POST | `/conversations` | BD | 201 `Conversation` | 401 |
| POST | `/conversations/{id}/messages` | BD | 200 `Message` (`kind` ∈ ANSWER/NOT_FOUND/ERROR) | 409 `NO_READY_DOCUMENTS`, 422 `QUESTION_*`, 503/504 `AI_*` |
| PUT | `/messages/{id}/feedback` | BD | 200 `Feedback` | 404 |
| GET | `/stats/weekly?from&to` | MANAGER | 200 `WeeklyStats[]` | 403 |
| POST | `/events` | Đăng nhập | 202 | 422 tên sự kiện ngoài danh sách |
| GET | `/healthz`, `/readyz` | Nội bộ | 200 | 503 |

**Error** = `{ "error": { "code", "message", "details?", "correlationId" } }`. Mã lỗi: `AUTH_REQUIRED`, `AUTH_INVALID`, `FORBIDDEN`, `NOT_A_PDF`, `FILE_TOO_LARGE`, `TOO_MANY_PAGES`, `LIBRARY_FULL`, `QUESTION_EMPTY`, `QUESTION_TOO_LONG`, `NO_READY_DOCUMENTS`, `AI_TIMEOUT`, `AI_QUOTA`, `AI_UNAVAILABLE`, `DOCUMENT_GONE`, `NOT_FOUND_RESOURCE`, `VALIDATION_ERROR`.

**Message** = `{ id, conversationId, role, kind, text?, citations: [{documentId, documentName, page, documentDeleted}], errorType?, createdAt }`.

**Document** = `{ id, name, sizeBytes, pageCount?, status, unusableReason?, retryable, uploadedBy, uploadedAt }`; `unusableReason` ∈ `scanned`, `password`, `corrupt`, `processing_failed`.
