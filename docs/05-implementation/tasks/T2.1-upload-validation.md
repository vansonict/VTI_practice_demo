## Mục tiêu

Từ chối sớm (trước khi lưu và xử lý) các file không hợp lệ, với mã lỗi và thông điệp nêu rõ giá trị thực và giới hạn.

## Bối cảnh

- Upload bị từ chối trước xử lý **không** tạo bản ghi `documents` (SDD §3.7).
- Giới hạn đặt trong cấu hình; giá trị tạm ghi rõ là tạm cho tới khi OQ-004 chốt.

## Phạm vi

**Trong phạm vi**

- Kiểm tra PDF theo **nội dung** (chữ ký tệp), không chỉ đuôi
- Giới hạn kích thước
- Giới hạn số trang (đọc nhanh số trang khi có thể)
- Giới hạn số tài liệu trong kho
- Giới hạn kích thước request ở reverse proxy

**Ngoài phạm vi**

- Phát hiện mật khẩu/hỏng/scan (T2.2, cần mở file)

## Các bước thực hiện

1. Đọc các giới hạn từ cấu hình: `MAX_FILE_MB`, `MAX_PAGES`, `MAX_DOCUMENTS`.
2. Kiểm tra chữ ký tệp PDF; sai → `NOT_A_PDF`.
3. Kiểm tra kích thước; vượt → `FILE_TOO_LARGE` kèm `details: { actualMb, limitMb }`.
4. Đọc số trang nếu thư viện cho phép đọc nhanh; vượt → `TOO_MANY_PAGES` kèm `{ actualPages, limitPages }`. Nếu không đọc được số trang ở bước này, để worker xử lý (T2.2).
5. Đếm tài liệu hiện có (trừ đã xóa); đầy → `LIBRARY_FULL` kèm `{ limit }`. Với upload nhiều file: tính lần lượt, file vượt giới hạn bị từ chối, file trước đó vẫn nhận.
6. Cấu hình giới hạn body ở reverse proxy lớn hơn `MAX_FILE_MB` × số file tối đa mỗi request một chút, để lỗi rõ ràng từ ứng dụng thay vì lỗi proxy.
7. Phát `document_upload_failed` với `failure_reason` tương ứng.

## Đặc tả

Thông điệp hiển thị (UI/UX §11): "`<tên>`: chỉ hỗ trợ file PDF." · "`<tên>`: file X MB vượt giới hạn Y MB." · "`<tên>`: kho đã đầy (N tài liệu). Hãy xóa tài liệu cũ rồi thử lại."

## Tiêu chí chấp nhận

- [ ] Given file `.pdf` nhưng nội dung là ảnh PNG, When upload, Then lỗi `NOT_A_PDF` và không có bản ghi `documents`.
- [ ] Given file lớn hơn giới hạn, When upload, Then lỗi `FILE_TOO_LARGE` với kích thước thực và giới hạn trong `details`.
- [ ] Given kho còn 1 chỗ và upload 2 file hợp lệ, When xử lý, Then file thứ nhất được nhận, file thứ hai lỗi `LIBRARY_FULL`.
- [ ] Không có tệp lưu trữ nào cho các file bị từ chối.
