## Mục tiêu

Dev chạy toàn bộ hệ thống trên máy cá nhân bằng một lệnh: CSDL + vector, kho tệp, API, worker, dịch vụ embedding (hoặc giả lập), frontend.

## Bối cảnh

- Mỗi tiến trình một container (ADR đóng gói, T0.1).
- Trong dev mặc định dùng adapter AI giả lập; không cần khóa API.

## Phạm vi

**Trong phạm vi**

- File cấu hình container cho dev
- Seed người dùng và tài liệu mẫu không nhạy cảm
- Biến môi trường mẫu (`.env.example`)

**Ngoài phạm vi**

- Môi trường test/pilot (T4.9)

## Các bước thực hiện

1. Định nghĩa các dịch vụ: `db` (PostgreSQL + vector, volume riêng), `files` (volume), `api`, `worker`, `embedding` (giả lập trước, thật ở T1.7), `web` (frontend dev server hoặc reverse proxy).
2. Chạy migration và seed tự động khi khởi động lần đầu.
3. Tạo `.env.example` liệt kê đủ biến (không có giá trị bí mật).
4. Thêm 3–5 PDF mẫu không nhạy cảm cho dev (gồm 1 file scan, 1 file có mật khẩu, 1 file hỏng để test lỗi).
5. Viết hướng dẫn chạy trong README; thời gian khởi động từ đầu được ghi lại.

## Tiêu chí chấp nhận

- [ ] Một lệnh khởi động đủ dịch vụ; `/readyz` trả 200.
- [ ] Đăng nhập được bằng tài khoản seed (khi T4.1 xong; trước đó API cho phép người dùng dev cố định).
- [ ] Không có dữ liệu thật hoặc khóa API trong repo.

## Kiểm thử

- Một người mới trong đội làm theo README, chạy được không cần hỏi.

## Definition of Done

- [ ] Mọi tiêu chí chấp nhận ở trên đạt và có bằng chứng (test, ảnh, log)
- [ ] Có test tự động tương ứng, chạy trong CI và xanh
- [ ] Không vi phạm quy tắc phụ thuộc (SDD §3.3); lõi không import SDK nhà cung cấp
- [ ] Lỗi dùng mã chuẩn (OpenAPI); `NOT_FOUND` và `ERROR` không bị lẫn
- [ ] Không ghi nội dung tài liệu/câu hỏi/câu trả lời vào log hoặc analytics
- [ ] Giao diện (nếu có) khớp thiết kế UI/UX và thao tác được bằng bàn phím
- [ ] Nếu chạm tới pipeline hỏi đáp: eval chạy lại không làm giảm MET-002/MET-005
- [ ] Code review đã duyệt; OpenAPI/README cập nhật nếu có thay đổi
