## Mục tiêu

Màn hình không gian làm việc tối thiểu gọi API thật: tải lên, danh sách có trạng thái (polling), gửi câu hỏi, hiển thị câu trả lời + trích dẫn.

## Bối cảnh

- Bản mẫu HTML là tham chiếu hành vi và giao diện; token lấy từ khối `:root` của bản mẫu.
- Trạng thái tài liệu do server quyết định, UI chỉ hiển thị.

## Phạm vi

**Trong phạm vi**

- Bố cục hai cột (kho 360 px + chat)
- Upload (nút + kéo-thả, nhiều file)
- Danh sách + badge trạng thái, polling `[Initial: 2 giây]` khi còn `PROCESSING`
- Ô nhập (Enter gửi, Shift+Enter xuống dòng)
- Hiển thị ANSWER (trích dẫn) và NOT_FOUND
- Lớp gọi API sinh từ/khớp OpenAPI

**Ngoài phạm vi**

- Lý do lỗi tài liệu, hộp thoại xóa, kho đầy (T2.6)
- Trạng thái lỗi/chờ lâu, hỏi tiếp, xem nguồn (T3.8)
- Đăng nhập (T4.1)

## Các bước thực hiện

1. Tạo trang S02 theo bố cục bản mẫu; dùng token màu, chữ, khoảng cách từ `styles/tokens`.
2. Component `UploadDropzone`, `DocumentItem`, `StatusBadge` (3 trạng thái, icon + chữ).
3. Polling `GET /documents` mỗi 2 giây khi có tài liệu `PROCESSING`; dừng khi không còn.
4. Component `Composer` (bộ đếm ký tự, vô hiệu khi rỗng/đang chờ/không có tài liệu sẵn sàng kèm dòng giải thích).
5. Component `ChatThread`, `AnswerMessage` (văn bản + `CitationChip` "tên, tr.N"), `NotFoundMessage` (kiểu riêng).
6. Chỉ báo "Đang tìm trong N tài liệu…" trong lúc chờ; chặn gửi trùng.
7. Khu vực `aria-live` thông báo có câu trả lời và tài liệu sẵn sàng.

## Tiêu chí chấp nhận

- [ ] Given trang S02, When chọn 1 PDF, Then tài liệu xuất hiện "Đang xử lý" ngay và tự chuyển "Sẵn sàng truy vấn" không cần tải lại trang.
- [ ] Given có tài liệu sẵn sàng, When gõ câu hỏi và nhấn Enter, Then thấy chỉ báo chờ rồi câu trả lời kèm ít nhất một trích dẫn dạng "tên tài liệu, tr.N".
- [ ] Given kết quả NOT_FOUND, When hiển thị, Then dùng kiểu "không tìm thấy" (khác câu trả lời thường).
- [ ] Toàn bộ thao tác trên làm được bằng bàn phím; focus nhìn thấy được.

## Kiểm thử

- Component test cho Composer, StatusBadge, AnswerMessage.
- E2E: upload → sẵn sàng → hỏi → thấy trích dẫn (adapter giả lập).
